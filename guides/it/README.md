# MelodyFinder - Informazioni Utili

### Questo script ti permette di:
1. Cercare video su YouTube.
2. Scaricare i video in MP3 o MP4.
3. Trovare testi sincronizzati automaticamente.

### Installazione
1. Assicurati di avere Python, `yt-dlp` e `ffmpeg` installati.

## Linux
```bash
sudo apt-get update -y && sudo apt-get upgrade -y && sudo apt-get install ffmpeg -y && pip3 install yt-dlp
```

## Windows
- Windows+X >> Prompt dei Comandi (Admin):
```batch
choco install ffmpeg && pip3 install yt-dlp
```

2. Configura il file configs.json come necessario (Vedi [Questa Guida](guides/it/configs-help.md) per maggiori informazioni)
# Uso
### Esegui lo script
```bash
python init.py
```
